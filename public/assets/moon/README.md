# Moon observation texture

`moon-global.png` is a browser-sized WMS export of the public-domain Clementine UV/VIS global lunar mosaic served by the USGS Astrogeology Science Center.

- Source layer: `uv_v2`
- Map service: https://planetarymaps.usgs.gov/cgi-bin/mapserv
- Dataset information: https://astrogeology.usgs.gov/search/map/moon_clementine_uvvis_global_mosaic_118m
- NASA LRO Moon Mosaic reference: https://svs.gsfc.nasa.gov/5001
